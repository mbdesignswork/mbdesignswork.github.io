Start with the board you need

A useful PCB design starts with the application: what the board must do, how it is powered, what connects to it and where it needs to fit. Work can begin with a functional description, a rough circuit, a development-module prototype or existing design files.

Support covers analog and control circuits, sensors, audio, lighting, displays, motor-control hardware and microcontroller-based prototypes. Board complexity, testing requirements and project suitability are reviewed before accepting the work.

From schematic to fabrication files

  • Circuit planning: block diagrams, power rails, interfaces, connector planning and component selection.
  • Altium schematic capture: organized schematics, part information and documented design decisions.
  • PCB layout: footprints, component placement, board outlines, mounting holes, stack-up planning and routing.
  • Design checks: electrical and layout checks, footprint verification and review against the agreed manufacturing requirements.
  • Build preparation: BOM preparation, Gerbers, drill files and agreed assembly documentation.

Source files and manufacturing outputs are defined in the project scope. Fabrication and assembly are separate costs; preparing a board for a prototype build does not establish that the finished product has passed every required test.

Existing boards and next revisions

If you already have a design, the work can focus on a specific problem: a connector change, a component replacement, layout cleanup or a revision after bring-up. Send the available source files and explain what should change so the existing work can be assessed first.

A schematic or PCB review can also be scoped separately. Findings identify suggested corrections, open questions and checks needed before the next build.

What to send

Start with the intended use, required inputs and outputs, supply voltage and expected loads, approximate board size, connector requirements and target timing. Mention the existing CAD tool, available files and whether you need design-only work or help with prototype bring-up.

For the next stage, see electronics prototyping and debugging. If the starting point is an undocumented physical board, see legacy PCB recreation.

Working remotely with your board manufacturer

You can use a fabricator or assembly shop in your own country. If you have chosen a shop, send its layer stack-up, layout rules and file checklist before routing starts. An enclosure drawing or 3D model helps us review connector access and mounting holes together.

For fabrication, the agreed handoff can include Gerber and drill files. For assembly, it can include a bill of materials and assembly notes. If you plan to power up the prototype at your own bench, include the checks you need in the project brief.
